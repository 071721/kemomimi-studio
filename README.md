# 兽耳工作室 Kemomimi Studio

一个纯前端的 Q 版角色换装小工具：给角色装上兽耳和尾巴，调表情、配色、动作，然后导出成图。
不需要安装任何依赖，双击 `index.html` 就能用，也可以直接托管在任意静态服务器上。

## 功能

**耳朵 / 尾巴** — 14 种动物造型：狐、狼、猫、狗、兔、虎、狮、猴、熊猫、鹿、松鼠、羊、浣熊、鲸。
每种都有配套的耳朵和尾巴形状，可分别调整大小、水平/垂直位置和倾斜角度。

**面部** — 表情、眼神、眼眶、口型、嘴巴、眉毛，五个维度各自独立可调。

**动作** — 整体动作之外，还有 6 种可叠加的局部动作：

| 动作 | 作用部位 |
| --- | --- |
| 扭头 | 头部 |
| 扭腰 | 躯干 |
| 扭屁股 | 裙摆 |
| 挥手（左 / 右 / 双手） | 手臂 |

不同部位的动作可以同时开启（比如一边扭头一边挥手），同一部位只能选一种（挥手类三选一）。
速度和幅度对整体动作与局部动作一起生效。

**其他** — 背景、配色、随机生成、导入自定义图片、保存 / 读取配置、导出图片。

## 实现说明

**渲染** 全部由 Canvas 2D 程序化完成，没有用任何游戏引擎或框架。角色立绘是位图，
耳朵、尾巴、五官、动作都是运行时用路径和渐变画出来的，所以可以任意调参数而不用准备素材。

**局部动作** 的实现是离屏变形：先把角色整体画到离屏 canvas，
用椭圆软边遮罩（并扣掉裙摆 / 头发）抠出目标区域，逐行横向错切后贴回主画布。
踩过的坑记在代码注释里——柔边会让「抹一半贴一半」留下半透明残影，逐行重叠会叠出横条纹，
所以最终是硬边遮罩 + 整数像素精确铺贴 + 只在朝身体内侧补缝。

**物理** 用弹簧模型，耳朵、尾巴、双马尾会跟着动作有惯性摆动。可以在设置里关掉。

## 本地运行

直接打开 `index.html` 即可。

修改了 `assets/chr/` 下的图片后，需要重新生成内嵌素材：

```bash
python tools/embed_assets.py
```
